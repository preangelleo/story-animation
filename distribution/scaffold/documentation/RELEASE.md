# 分发边界
本包是干净的独立投影，不包含原仓库 Git 历史、个人密钥/账号、克隆声音ID/音频、客户资料、SSH/主机/个人路径、真实作品、预算账本、授权原件或私人报告。源码与26风格可编辑，素材/字体权利仍由使用者负责。

离线测试是真实确定代码与合成媒体验证，供应商边界mock；不能充当用户账户的在线验收。首次付费运行、模型额度、字体安装、实际听感、独立频道OAuth与真实排期需在自己的环境完成。

默认 Build，未自动启动timer、未进入Operate；接收者必须自行批准自己的制作与发布。样片被原作者接受只作为流程来源事实，不继承其授权、预算或频道身份。

包为 Agent J workflow：manifest.json allowlist，scaffold/ 安装到独立工作区。500文件/8MiB总文件/2MiB压缩包/64KiB manifest限制由本地真实 bundle.build/parse 检查。发布时还需现行广场审查，不以这里的离线检查冒称已上架。

包内负控测试保留运动、字幕底带、路径与重复索引等拒绝案例；用于模拟提示注入的两条原始自然语言攻击句，以及一个形似邮箱的URL-userinfo向量未随包分发，避免把攻击指令/邮箱样式文本放进公开安装内容。运行时拒绝规则完整保留，未改广场扫描规则或白名单。
